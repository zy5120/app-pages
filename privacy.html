小鱼六壬 隐私政策

最后更新：2026年7月13日

数据收集

小鱼六壬不收集任何个人信息。所有起课历史记录仅存储在您的设备本地，不会上传至开发者服务器。

网络使用

核心起课功能完全离线运行，无需网络连接。

当您主动使用 AI 智能解读功能时，应用会将您当前卦象的上下文信息（掌诀名称、断辞、起课方式）及您选择填写的问题，发送至您自行配置的第三方 AI 服务商（如 DeepSeek、通义千问等）。具体说明：

  • 您需要自行申请并填写对应服务商的 API Key，该 Key 仅存储在设备本地
  • 数据传输直接从您的设备到服务商服务器，不经由小鱼六壬开发者
  • AI 解读的数据处理受该服务商自身的隐私政策约束
  • 如不配置 AI 功能，应用不会发起任何网络请求

第三方服务

本应用不使用任何第三方分析、广告或跟踪服务。AI 解读所使用的第三方 API 由您自行选择并配置，不属于本应用集成的第三方服务。

数据安全

所有本地数据（起课记录、API Key 配置）由 iOS 系统沙盒机制保障。删除应用即永久清除所有本地数据。

儿童隐私

本应用不面向13岁以下儿童，亦不会有意收集儿童的个人信息。
